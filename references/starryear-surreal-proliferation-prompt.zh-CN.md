# 星年·超现实增殖｜无尽克隆提示规范

## 核心命题

把一张源照片转化为竖向上—中—下三段式作品，主要表达**无尽复制带来的荒诞感**。中段是未经生成、未经修饰的原图裁切；上段与下段大胆重构主体和场景，各自建立不同的超现实复制世界。源图只提供主体身份、色彩、材质与气氛，不提供生成段的构图模板。上下段必须主动打破原图的位置、数量、朝向、尺度层级、景深顺序、镜头关系和留白形状，不能像给中段加了更多复制品。

## 硬性结构

不要一次生成完整三联画。上段与下段分两次生成；中段完全不进入生成模型。最后使用 `scripts/compose_triptych.py` 将源文件真实像素裁切后嵌入中间。

中段只允许裁切、等比缩放和定位。禁止生成、重绘、扩图、修图、调色、滤镜、锐化、颗粒、遮罩、叠字、覆盖元素或改变主体数量。

## 生成前内部分析

仅在内部完成，不输出分析文字：

1. 确认主体不可替代的身份特征：轮廓、结构、姿态、颜色、材质、表情或局部标记。
2. 把“身份证据”与“布局证据”分开：前者可保留，后者必须主动舍弃。不要沿用主体的原始坐标、数量关系、左右/上下对应、朝向、尺度层级、遮挡顺序、地平线位置或负空间轮廓。
3. 从原图提取 3–5 个主导色，确定统一色温、明暗关系、光源/天气逻辑、表面质感、边缘处理、颗粒和锐度。
4. 找出一个可被放大的矛盾，如“大量却孤独”“相同却互相制造”“沉重却漂浮”“微小却构成建筑”“主体复制到吞没原场景”。
5. 为上下段分别写出一句不同的新空间命题。两句话都不能只是描述原图，若可互换或仍能对应原图布局，重新设计。
6. 先确定新镜头、新空间骨架、新主锚点和新运动方向，再开始复制。禁止先照搬原图构图、再往空隙里添加克隆。

## 全局艺术指导

- 上下段都必须清晰复制源图主体、主体局部或两者组合；复制是视觉主角，不是装饰花纹。
- 允许大胆改造原场景：拉伸、折叠、翻转、掏空、压缩、建筑化、舞台化，或让场景由克隆体本身构成。
- 保留主体辨识度。夸张数量、尺度、空间和因果，不把主体随意变成另一种物体。
- 辨识度只约束主体身份，不保护原图构图。生成段不得刻意复现源图主要主体所在画面分区、主体之间的相对位置、朝向组合、前后层级、原始地平线和留白地图。
- 上下段的最大或最清晰锚点，原则上应移动到与源图锚点不同的画面三分区；若题材不适合机械移动，则必须通过视点、方向、尺度或空间结构产生同等强度的构图脱离。
- 上下段统一使用源图提炼的核心色组；允许扩大饱和度或明暗跨度，但不要各自建立互不相干的调色方案。
- 上下段统一画风与完成度：同一类光线、材质响应、纹理/笔触、边缘软硬、颗粒、对比度和空气感。可选择摄影现实、干燥绘画、丝网印刷、纸感拼贴或雕塑舞台等一种主语言，但两段必须一致。
- 不要求上下段延续同一地点或同一镜头；要求它们属于同一个审美世界。

## 上段｜数量失控的克隆世界

以源照片为唯一主体依据，生成一幅横向满幅画面，用于成品上段。目标是第一眼就让人感到“多得不可能”，重点表现复制数量、密度和尺度的失控。

从以下逻辑中选择最适合源图的一种：

- 一个主体裂变出几十、几百个克隆，向远方、天空或建筑深处无尽延伸；
- 克隆体按尺度瀑布递进，从巨大到微小，直至成为地形、云层、墙体或地平线；
- 主体内部继续嵌套主体，形成递归繁殖，但每层仍能辨认来源；
- 克隆像潮汐、迁徙、队列、虫群或失控生产线一样吞没场景；
- 主体的关键局部大量繁殖，少量完整主体作为见证失控的锚点。

构图必须有密度梯度、遮挡、尺度差和清晰流向。必须选择源图中不存在的新视点与主流向，并把最大锚点移出源图对应位置。可极度密集，但保留一块全新形状的负空间，让荒诞关系可读。禁止整齐矩阵、壁纸平铺、同姿势同尺寸盖章、单纯复制粘贴，或保留源图构图后只增加数量。上段不要把因果循环、功能倒置、承载悖论或重力反转作为主要机制。

## 下段｜规则失灵的克隆世界

以同一源照片为唯一主体依据，生成另一幅横向满幅画面，用于成品下段。仍然存在大量复制，但荒诞感主要来自空间、功能、因果、重力或层级关系失灵，而非仅仅“更多”。

从以下逻辑中选择与上段不同的一种：

- 克隆体互相搬运、穿戴、支撑或供奉，形成不可能的层级链；
- 一个克隆正在生产另一个克隆，后者又生产更小的克隆，形成闭环因果；
- 克隆体组成楼梯、桥、房间、山体、街道或容器，主体同时成为场景；
- 重力方向被改写，不同克隆站在墙面、天花板或折叠地面上；
- 场景出现递归房间、循环道路或镜像空间，但不是简单镜面复制；
- 一个巨大克隆与大量微小克隆发生荒诞任务关系，构成清楚而不解释的事件。

必须有一个醒目的主事件、至少一个接近原图尺度的辨识锚点，并让重复沿着空间或因果关系展开。允许舞台化和强烈尺度错乱，但避免无依据漂浮、无接触感堆叠和看不清主体的混乱。

这个辨识锚点不得回到源图主要主体的对应位置或复制其邻接关系。下段应像进入同一视觉世界里的另一套物理法则，而不是从中段自然向下延展。

## 构图独立性门槛

每个生成段完成后，都要与中段裁切进行一次构图对照。以下任一情况出现即判定失败并重新生成：

- 最大或最清晰主体落在与中段主锚点相同的画面三分区；
- 两个及以上主体重复中段可辨认的左右、上下或前后位置关系；
- 主要轮廓、地平线、密度分布或负空间形状仍像原图；
- 把生成段概括为“原图构图加了更多复制品”仍然成立；
- 只改变风格、数量或局部尺度，没有更换镜头、空间骨架、方向或主事件。

失败时不要做轻微挪动。重新选择视点、主锚点分区、运动方向和空间机制，确保结构性变化。

## 统一与差异检查

- **差异**：上段主要是数量/尺度/密度失控；下段主要是空间/功能/因果/重力失灵。
- **统一**：两段的核心色组、色温、光线气质、材质、纹理/笔触、边缘处理、颗粒和完成度一致。
- **来源**：所有主要克隆体的身份与视觉 DNA 都能追溯到源图，但其构图坐标与舞台关系不得追溯原图；不添加抢夺主题的陌生物种、符号、宇宙、霓虹、魔法光效或装饰性梦境元素。
- **荒诞**：画面必须像一个无法成立、却一眼能读懂的命题；如果只是“同一个东西变多了”，继续重构空间或因果。

## 明确排除

排除普通复制粘贴、源图位置描摹、同位置主角、原构图加量、规整九宫格、壁纸图案、万花筒、纯镜像、完全相同的姿态与尺度、剪贴白边、漂浮贴纸、错误穿插、粘连、肢体/结构畸变、主体身份丢失、无关物体、上下两段不同画风、上下两套调色、通用雾气、光晕、星空、霓虹、文字、边框、分栏线、标题、Logo、签名和水印。

## 确定性合成

上下段通过后运行：

```bash
python scripts/compose_triptych.py --top TOP.png --source ORIGINAL.jpg --bottom BOTTOM.png --output FINAL.png
```

默认画布 1536×2304，段高 34/24/42，使中段更像一条冷静的现实证据，给下段更充分的重构空间。需要时可用 `--ratios` 调整；用 `--crop x,y,w,h` 指定源图裁切。合成后禁止对整图应用任何会改变中段像素的效果。

## 验收与输出

1. 中段确实来自源文件真实像素，只裁切与等比缩放。
2. 第一眼能读到“无尽克隆”的荒诞主题。
3. 上下段能分别用两句不同的话概括，不能只是同一构图上下翻版。
4. 上下段均未复刻中段的主锚点位置、主体关系、深度顺序、流向或负空间地图；不能用“原图构图加量”概括。
5. 上下段色调与画面语言一致，即使场景被完全重构。
6. 克隆体辨识清楚，数量节奏、遮挡、尺度、空间接触与负空间可读。
7. 最终只返回一张无文字、无边框、无水印的竖向成品；除非用户要求，不单独返回上下段。
